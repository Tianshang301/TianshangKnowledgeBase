# 香农信息论

Claude Shannon于1948年发表的《A Mathematical Theory of Communication》奠定了信息论的基础，为通信、数据压缩、密码学等领域提供了数学框架。信息论的核心问题是：信息如何度量、如何高效传输、如何可靠传输。

## 信息熵、条件熵、互信息

### 信息熵（Shannon Entropy）

度量随机变量的不确定性：

$$H(X) = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x)$$

- 单位为bit（以2为底）或nat（以e为底）
- 均匀分布时熵最大：$H(X) = \log_2 |\mathcal{X}|$
- 确定性事件熵为0
- 例：公平硬币 $H = 1$ bit，公平骰子 $H = \log_2 6 \approx 2.58$ bits

### 联合熵与条件熵

联合熵：

$$H(X, Y) = -\sum_{x,y} p(x,y) \log_2 p(x,y)$$

条件熵：

$$H(Y|X) = -\sum_{x} p(x) \sum_{y} p(y|x) \log_2 p(y|x)$$

链式法则：$H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)$

### 互信息（Mutual Information）

度量两个随机变量之间的相互依赖程度：

$$I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$$

$$I(X; Y) = \sum_{x,y} p(x,y) \log_2 \frac{p(x,y)}{p(x)p(y)}$$

- $I(X;Y) \geq 0$，等号成立当且仅当X和Y独立
- 对称：$I(X;Y) = I(Y;X)$
- 是信道容量定义的基础

### KL散度

Kullback-Leibler散度度量两个概率分布的差异：

$$D_{KL}(P \| Q) = \sum_{x} p(x) \log_2 \frac{p(x)}{q(x)}$$

- 非负：$D_{KL} \geq 0$
- 不对称：$D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$
- 与互信息关系：$I(X;Y) = D_{KL}(p(x,y) \| p(x)p(y))$

## 信道容量定理

### 信道模型

通信信道由输入X、输出Y和转移概率 $p(y|x)$ 描述。

### 信道容量

$$C = \max_{p(x)} I(X; Y)$$

即所有可能输入分布中互信息的最大值。

### Shannon信道编码定理

**定理**：对于信道容量为C的信道，只要传输速率 $R < C$，存在编码方案使得错误概率任意接近0。反之，若 $R > C$，则不可能实现可靠传输。

意义：
- 给出了可靠通信的基本极限
- 证明了编码的存在性（但未给出构造方法）
- 指导了后续几十年的编码研究

### 典型信道容量

- **BSC（二进制对称信道）**：$C = 1 - H(p)$，p为翻转概率
- **AWGN信道**：$C = \frac{1}{2} \log_2(1 + \text{SNR})$（连续情况）

## 信源编码

信源编码的目标是用尽可能少的比特表示信源输出，即数据压缩。

### 无损编码

#### 霍夫曼编码（Huffman Coding）

- 贪心算法：频率低的符号用长编码，频率高的用短编码
- 构造过程：自底向上构建二叉树
- 性质：前缀码，无歧义解码
- 局限：编码长度必须为整数比特，当信源熵较低时效率不高

#### 算术编码（Arithmetic Coding）

- 将整个消息编码为一个区间内的实数
- 突破了霍夫曼编码的整数比特限制
- 接近信源熵的理论极限
- 广泛用于JPEG、H.264/265等标准

#### LZW编码

- 基于字典的通用压缩方法
- 动态构建字典，无需预知符号频率
- GIF图像格式使用的压缩算法

### 信源编码定理

**Shannon信源编码定理**：对长度为n的独立同分布信源序列，最小平均编码长度趋近于信源熵 $H(X)$。

$$\lim_{n \to \infty} \frac{L_{min}}{n} = H(X)$$

## 信道编码

信道编码通过添加冗余来对抗信道噪声，实现可靠传输。

### 纠错码基础

核心思想：在信息比特中添加冗余的校验比特，接收端利用冗余检测和纠正错误。

- **码率** $R = k/n$：k个信息比特编码为n个码字比特
- **汉明距离**：两个码字不同位的个数
- **最小距离** $d_{min}$：码集中任意两个码字的最小汉明距离
- 纠t个错误需要 $d_{min} \geq 2t + 1$

### 主要编码类型

- **分组码**：信息分组独立编码（汉明码、BCH码、RS码）
- **卷积码**：利用移位寄存器产生有记忆的编码
- **级联码**：内外码串联，如RS码+卷积码
- **Turbo码**：两个递归系统卷积码并行级联 + 迭代译码
- **LDPC码**：稀疏校验矩阵的线性码，接近Shannon极限
- **Polar码**：基于信道极化，理论上可达信道容量

### Shannon极限

对于AWGN信道，可靠传输所需的最小 $E_b/N_0$ 为 -1.59 dB。这是所有编码方案的理论下界。

## 率失真理论

有损压缩的理论基础，研究在允许一定失真下的最低编码速率。

### 率失真函数

$$R(D) = \min_{p(\hat{x}|x): \mathbb{E}[d(x,\hat{x})] \leq D} I(X; \hat{X})$$

即在平均失真不超过D的条件下，$I(X;\hat{X})$ 的最小值。

### 常见失真度量

- **汉明失真**：$d(x,\hat{x}) = \mathbb{1}[x \neq \hat{x}]$
- **均方误差**：$d(x,\hat{x}) = (x - \hat{x})^2$

### 高斯信源

均方误差下的率失真函数：

$$R(D) = \frac{1}{2} \log_2 \frac{\sigma^2}{D}, \quad 0 \leq D \leq \sigma^2$$

### 应用

- 图像压缩（JPEG、WebP）
- 音频压缩（MP3、AAC）
- 视频压缩（H.264/265、AV1）
- 语音压缩（Opus）
