# 扩散模型 (Diffusion Models)

## 1. 基本原理

扩散模型是一类基于概率的生成模型，通过学习数据的分布来生成新的样本。其核心思想包含两个过程：

### 1.1 前向扩散过程 (Forward Diffusion)

逐步向数据添加高斯噪声，直到数据完全变为噪声。

```
x₀ → x₁ → x₂ → ... → xₜ → ... → xₜ (纯噪声)
```

**数学表达**：
```
q(xₜ | xₜ₋₁) = N(xₜ; √(1-βₜ) xₜ₋₁, βₜI)
```

其中 βₜ 是预定义的噪声调度（noise schedule）。

### 1.2 反向去噪过程 (Reverse Denoising)

学习从噪声中逐步恢复原始数据。

```
xₜ → xₜ₋₁ → ... → x₁ → x₀ (生成的数据)
```

**数学表达**：
```
pθ(xₜ₋₁ | xₜ) = N(xₜ₋₁; μθ(xₜ, t), Σθ(xₜ, t))
```

## 2. 数学基础

### 2.1 DDPM (Denoising Diffusion Probabilistic Models)

2020年由Ho等人提出的奠基性工作。

**关键创新**：
- 简化预测目标：模型只需预测噪声 ε
- 固定方差，只学习均值
- 简单的MSE损失函数

**训练目标**：
```
L = E[||ε - εθ(xₜ, t)||²]
```

### 2.2 得分匹配 (Score Matching)

**得分函数**：
```
s(x) = ∇x log p(x)
```

**去噪得分匹配**：
```
sθ(xₜ, t) ≈ -εθ(xₜ, t) / √(1-ᾱₜ)
```

### 2.3 随机微分方程 (SDE)

Song等人将离散的扩散过程推广为连续的随机微分方程。

**前向SDE**：
```
dx = f(x, t)dt + g(t)dw
```

**反向SDE**：
```
dx = [f(x, t) - g(t)²∇x log pₜ(x)]dt + g(t)dw̄
```

## 3. 代表性模型

### 3.1 Stable Diffusion

由Stability AI开源的文本到图像生成模型。

**架构组成**：
```
文本编码器(CLIP) → 潜空间 → U-Net → VAE解码器 → 图像
```

**关键特点**：
- 在潜空间（Latent Space）进行扩散，大幅降低计算成本
- 使用Classifier-Free Guidance提升生成质量
- 开源生态丰富，社区活跃

**版本演进**：
| 版本 | 发布时间 | 特点 |
|------|----------|------|
| SD 1.5 | 2022.10 | 基础版本，广泛使用 |
| SD 2.0 | 2022.11 | 更高分辨率，改进的文本编码器 |
| SDXL | 2023.7 | 更大模型，更好的质量 |
| SD 3.0 | 2024.6 | 采用DiT架构 |
| SD 3.5 | 2024.10 | 开源版本，多种变体 |

### 3.2 DALL-E 3

OpenAI的文本到图像生成模型。

**技术亮点**：
- 强大的文本理解能力
- 精确的文字渲染
- 与ChatGPT深度集成

### 3.3 Midjourney

以美学质量著称的图像生成服务。

**特点**：
- 艺术风格多样
- 高质量的视觉效果
- 持续的版本迭代（V5、V6、V7）

### 3.4 Sora (视频生成)

OpenAI于2024年2月发布的视频生成模型。

**技术突破**：
- 生成长达60秒的高质量视频
- 复杂的物理世界模拟能力
- 基于Diffusion Transformer架构

## 4. 关键技术

### 4.1 U-Net架构

传统扩散模型的核心网络结构。

```
┌─────────────────────────────────────────┐
│              U-Net 架构                  │
│  ┌─────────────────────────────────┐    │
│  │         下采样路径               │    │
│  │  Conv → ResBlock → Attention    │    │
│  │           ↓                     │    │
│  │         Bottleneck              │    │
│  │           ↓                     │    │
│  │         上采样路径               │    │
│  │  Upsample → ResBlock → Attention│    │
│  └─────────────────────────────────┘    │
│         + 时间步嵌入 (Timestep)          │
│         + 条件嵌入 (Text/Class)          │
└─────────────────────────────────────────┘
```

### 4.2 DiT (Diffusion Transformer)

将Transformer架构引入扩散模型。

**优势**：
- 更好的扩展性（Scaling Laws）
- 更高效的注意力机制
- 更适合处理高分辨率图像

**代表模型**：
- Sora (OpenAI)
- Stable Diffusion 3
- PixArt系列

### 4.3 Classifier-Free Guidance (CFG)

通过同时训练条件和无条件模型来提升生成质量。

**推理公式**：
```
ε̃ = εuncond + w · (εcond - εuncond)
```

其中 w 是引导强度（guidance scale），通常设置为7-15。

## 5. 加速方法

### 5.1 DDIM (Denoising Diffusion Implicit Models)

将随机过程变为确定性过程，实现更快的采样。

**核心思想**：
- 跳过中间步骤
- 确定性采样
- 50步即可获得较好效果（vs DDPM的1000步）

### 5.2 一致性模型 (Consistency Models)

由Song等人提出，实现单步或少步生成。

**原理**：
- 学习从任意噪声水平直接映射到干净数据
- 支持单步生成
- 适合实时应用

### 5.3 LCM (Latent Consistency Models)

在潜空间中的一致性模型。

**优势**：
- 4-8步即可生成高质量图像
- 可与LoRA等技术结合
- 适合实时交互应用

### 5.4 蒸馏方法

| 方法 | 步数 | 质量 | 速度 |
|------|------|------|------|
| 原始DDPM | 1000 | 高 | 极慢 |
| DDIM | 50 | 高 | 中等 |
| LCM | 4-8 | 较高 | 快 |
| 一致性模型 | 1-4 | 中等 | 极快 |

## 6. 应用场景

### 6.1 图像生成

- **文本到图像**：根据文字描述生成图像
- **图像编辑**：局部修改、风格迁移
- **图像修复**：填补缺失区域
- **超分辨率**：提升图像分辨率

### 6.2 视频生成

- **文本到视频**：根据文字描述生成视频
- **视频编辑**：修改视频内容
- **视频插帧**：生成中间帧
- **视频风格化**：改变视频风格

### 6.3 3D生成

- **文本到3D**：根据文字描述生成3D模型
- **图像到3D**：从单张图像重建3D
- **3D编辑**：修改3D模型

### 6.4 音频生成

- **音乐生成**：AI作曲
- **语音合成**：文本到语音
- **音效生成**：环境音、音效

### 6.5 分子设计

- **药物分子生成**：设计新的药物分子
- **蛋白质结构预测**：预测蛋白质折叠
- **材料设计**：设计新材料

## 7. 2025-2026年最新进展

### 7.1 Sora的后续发展

- **更长视频生成**：支持数分钟的视频
- **更强的物理理解**：更准确的物理模拟
- **商业化应用**：影视、广告、游戏等领域的应用

### 7.2 Flux模型

由Stability AI前团队推出的新型扩散模型。

**特点**：
- 基于DiT架构
- 更好的文本理解
- 高质量的图像生成

### 7.3 实时生成

- **LCM的普及**：4步生成成为标准
- **流式生成**：实时预览和交互
- **移动端部署**：在手机上运行扩散模型

### 7.4 多模态扩散

- **统一的多模态生成**：文本、图像、视频的统一生成
- **交互式生成**：用户可以实时修改和指导生成
- **个性化生成**：根据用户偏好定制生成

## 8. 挑战与未来方向

### 8.1 可控性

- 如何精确控制生成内容的细节
- 空间布局、姿态、表情的精确控制
- 多条件组合的控制

### 8.2 版权争议

- 训练数据的版权问题
- 生成内容的版权归属
- 艺术家权益保护

### 8.3 训练成本

- 大规模扩散模型的训练需要巨大计算资源
- 数据收集和处理的成本
- 环境影响（碳排放）

### 8.4 评估标准

- 缺乏统一的评估指标
- 主观质量评估的标准化
- 多样性与质量的平衡
