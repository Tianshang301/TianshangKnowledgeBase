# 人形机器人控制

人形机器人控制是机器人学的前沿领域，涉及双足行走、全身协调运动等复杂控制问题。

## 步态规划与控制

### ZMP（零力矩点）稳定性判据

ZMP是双足行走稳定性的核心判据：

- **物理定义**：地面反力合力矩水平分量为零的点
- **稳定判据**：ZMP在支撑多边形内则机器人稳定，否则失稳
- **计算方法**：基于全身动力学方程，考虑惯性力、重力、外力
- **数学表达**：
  - $x_{zmp} = \frac{\sum m_i(\ddot{z}_i+g)x_i - \sum m_i\ddot{x}_i z_i}{\sum m_i(\ddot{z}_i+g)}$
- **ZMP参考轨迹规划**：通常规划在支撑足中心，摆动时在支撑多边形内
- **测量方法**：六维力传感器（脚底）测量地面反力
- **ZMP与CoP**：在准静态情况下ZMP等于压力中心（CoP）
- **局限性**：不适用于完全欠驱动阶段（如脚趾离地后的飞行相）

### CoM（质心）轨迹规划

质心运动是步态规划的核心：

- **线性倒立摆模型（LIPM）**：
  - 将机器人简化为集中质量点+无质量腿
  - CoM高度恒定假设
  - 运动方程：$\ddot{x} = \frac{g}{z_0}(x - x_{zmp})$
  - 解析解：双曲函数形式
- **捕获点（Capture Point）**：
  - 定义：使机器人在一步内停下来的CoM位置
  - 公式：$\xi = x + \frac{\dot{x}}{\omega}$，$\omega=\sqrt{g/z_0}$
  - 应用：平衡恢复、步态切换
- **CoM轨迹生成方法**：
  - 三次样条插值：平滑轨迹
  - 多项式插值：满足边界条件
  - ZMP预观控制：Kajita预观控制器
  - MPC优化：滚动优化轨迹
- **实时CoM调整**：
  - 基于ZMP反馈修正CoM轨迹
  - 踝关节力矩调节
  - 躯干姿态补偿
- **质心角动量（CAM）**：
  - 考虑全身角动量变化
  - CAM对步态稳定性的影响
  - 踢球等动态动作需要考虑
- **DCM（Divergent Component of Motion）**：
  - 改进的稳定性判据
  - DCM动力学：$\dot{\xi} = \omega(\xi - r)$
  - DCM规划比ZMP规划更直观

### 步态生成方法

- **离线预设步态**：
  - 离线规划关节轨迹
  - 适用于简单、重复场景
  - 缺点：无法应对扰动
- **CPG（中枢模式发生器）**：
  - 生物启发：脊髓神经振荡器网络
  - 振荡器模型：Matsuoka神经振荡器、Hopf振荡器
  - 特点：自适应节律、扰动恢复
  - 优点：鲁棒性好、易于调参
  - 缺点：精确位置控制困难
- **基于优化的步态规划**：
  - COLTRI（约束优化轨迹）
  - 轨迹优化（TO）：直接配点法、打靶法
  - 多步预观：规划多步未来轨迹
  - 考虑约束：关节限位、力矩限位、摩擦锥
- **强化学习步态**：
  - PPO/SAC算法训练
  - 仿真训练：Isaac Gym大规模并行
  - Sim2Real迁移：域随机化
  - 端到端策略：传感器输入→关节力矩输出
  - 优点：适应性强、可处理复杂地形
- **模型预测控制（MPC）**：
  - 滚动优化：每步求解优化问题
  - 预测模型：简化动力学模型（单刚体/全刚体）
  - 计算效率：1kHz以上实时求解
  - 应用：动态行走、跑步、跳跃

### 双足行走动力学特性

- **欠驱动阶段**：
  - 脚趾离地后，自由度大于驱动器数
  - 被动动力学：能量守恒
  - 欠驱动步行器：纯机械行走
- **混合动力学**：
  - 支撑相/摆动相：不同动力学模型
  - 事件触发切换：脚触地/离地事件
  - 冲击模型：碰撞瞬间速度跳变
- **接触力约束**：
  - 摩擦锥约束：$|F_t| \leq \mu F_n$（库仑摩擦模型）
  - 法向力非负：$F_n \geq 0$（只能推不能拉）
  - ZMP约束：等价于摩擦锥的线性化
- **步行速度与步态参数**：
  - 步频：每分钟步数
  - 步长：单步距离
  - 步行周期：一步时间
  - 速度=步长×步频
  - Froude数：$Fr = v^2/(gl)$，无量纲速度
- **被动行走**：
  - 纯机械结构下坡行走
  - 利用重力驱动
  - COT（能量消耗指标）极低
- **能量效率**：
  - COT（Cost of Transport）：$E/(mgl)$
  - 人类步行COT≈0.2
  - 人形机器人COT通常>1.0

## 全身运动控制（WBC）

### WBC系统架构

协调全身各关节完成复杂任务：

- **任务空间定义**：
  - 左/右手末端位置和姿态（6DOF×2）
  - 左/右脚末端位置和姿态（6DOF×2）
  - 躯干姿态（3DOF）
  - CoM位置（3DOF）
  - 头部姿态（3DOF）
  - 总任务自由度可达30+
- **任务优先级层次**：
  - 高优先级：安全约束（关节限位、自碰撞避免）
  - 中优先级：主要任务（末端位置、姿态）
  - 低优先级：次要任务（关节舒适姿态、能耗最小）
  - 优先级处理：严格优先级或加权组合
- **约束处理**：
  - 关节位置限位：$q_{min} \leq q \leq q_{max}$
  - 关节速度限位：$|\dot{q}| \leq \dot{q}_{max}$
  - 关节力矩限位：$|\tau| \leq \tau_{max}$
  - 接触约束：脚不滑移、不离地（期望时）
  - 自碰撞避免：关节间最小距离
- **实时性要求**：控制频率>1kHz（1ms周期）
- **冗余自由度利用**：人形机器人通常30-50DOF，远多于任务所需

### 基于二次规划（QP）的WBC

将WBC转化为QP问题求解：

- **决策变量**：关节加速度$\ddot{q}$、接触力$F_c$、关节力矩$\tau$
- **目标函数**：
  - 主任务跟踪误差最小：$||J\ddot{q}+\dot{J}\dot{q}-\ddot{x}_d||^2$
  - 正则化项：$||\ddot{q}||^2$或$||\tau||^2$（防止过大）
  - 多任务加权：$\sum_i w_i ||e_i||^2$
- **等式约束**：
  - 浮基动力学方程：$M(q)\ddot{q}+C(q,\dot{q})+g(q)=S^T\tau+J_c^T F_c$
  - 接触运动学约束：$J_c\ddot{q}+\dot{J}_c\dot{q}=0$
- **不等式约束**：
  - 摩擦锥约束：线性化锥约束
  - 关节力矩上下限：$-\tau_{max} \leq \tau \leq \tau_{max}$
  - 接触力上下限：$0 \leq F_n \leq F_{n,max}$
- **求解器**：OSQP、qpOASES、eiquadprog
- **计算效率**：QP求解<1ms，满足实时要求

### 逆动力学计算

计算实现期望运动所需的关节力矩：

- **牛顿-欧拉递推法**：
  - 向前递推：从基座到末端，计算速度和加速度
  - 向后递推：从末端到基座，计算力和力矩
  - 复杂度：$O(n)$，n为关节数
  - 效率高，适合实时控制
- **拉格朗日法**：
  - 解析表达：$M(q)\ddot{q}+C(q,\dot{q})\dot{q}+g(q)=\tau$
  - 惯性矩阵$M(q)$：对称正定
  - 科氏力/离心力$C(q,\dot{q})$
  - 重力项$g(q)$
  - 便于分析，但计算量$O(n^3)$
- **浮基动力学**：
  - 基座不固定（人形机器人）
  - 基座6DOF+关节nDOF
  - 虚拟关节处理
  - 动力学方程更复杂
- **接触力建模**：
  - 地面反力模型：弹簧-阻尼模型
  - 摩擦模型：库仑摩擦、Stribeck效应
  - 软接触模型：Hunt-Crossley模型
- **动力学计算库**：
  - Pinocchio（C++/Python）：高效，支持浮基
  - RBDL（C++）：轻量级
  - Drake（C++）：MIT开发，仿真+控制
  - MuJoCo：物理仿真引擎

### 运动学基础

- **正运动学**：关节角度→末端位置/姿态
  - DH参数法：标准/改进DH
  - 齐次变换矩阵
- **逆运动学（IK）**：末端位置/姿态→关节角度
  - 解析法：封闭解（特定构型）
  - 数值法：雅可比迭代、牛顿法
  - 冗余IK：多解情况，优化选择
- **雅可比矩阵**：$J(q): \dot{q} \rightarrow \dot{x}$
  - 几何雅可比
  - 解析雅可比
- **奇异性**：雅可比矩阵秩亏
  - 工作空间边界奇异
  - 内部奇异（臂/腿完全伸展）
  - 奇异回避：阻尼最小二乘（DLS）

## 力矩控制与柔顺控制

### 阻抗控制

调节机器人与环境交互的动态关系：

- **阻抗控制数学模型**：
  - $M_d(\ddot{x}-\ddot{x}_d) + B_d(\dot{x}-\dot{x}_d) + K_d(x-x_d) = F_{ext}$
  - $M_d$：期望惯性矩阵
  - $B_d$：期望阻尼矩阵
  - $K_d$：期望刚度矩阵
- **参数物理意义与调节**：
  - 刚度K：位置响应刚性，K大→硬接触，K小→软接触
  - 阻尼B：振动抑制，B=2$\sqrt{KM}$为临界阻尼
  - 惯性M：动态响应，通常设为实际惯性
- **关节空间阻抗控制**：
  - 直接控制关节力矩
  - $\tau = \tau_{ff} + K_p(q_d-q) + K_d(\dot{q}_d-\dot{q})$
- **任务空间阻抗控制**：
  - 控制末端力/位关系
  - 适用于操作任务
- **变阻抗控制**：
  - 根据任务阶段调整阻抗参数
  - 接触前：高刚度（精确位置）
  - 接触后：低刚度（柔顺交互）
- **在线阻抗调节**：基于力反馈实时调整

### 力矩控制实现

- **电流环控制**：
  - 电机力矩直接控制
  - 力矩=电流×力矩常数（Kt）
  - 带宽：>1kHz
  - 适用于关节力矩电机
- **关节力矩传感器**：
  - 应变片式力矩传感器
  - 安装位置：电机端/连杆端
  - 提高力矩控制精度
  - 无传感器力估计：基于电流观测
- **力/位混合控制**：
  - 不同方向不同控制策略
  - 切向：位置控制（轨迹跟踪）
  - 法向：力控制（接触力保持）
  - 选择矩阵S：0-1对角矩阵
- **导纳控制**：
  - 力输入→位置输出
  - 适用于刚性环境
  - $M_d\ddot{x}+B_d\dot{x}+K_d(x-x_d)=F_{ext}$
- **力矩前馈补偿**：
  - 重力补偿：$\tau_g = g(q)$
  - 摩擦力补偿：$\tau_f = f_v\dot{q}+f_c sgn(\dot{q})$
  - 惯性补偿：$\tau_m = M(q)\ddot{q}_d$
  - 科氏力补偿：$\tau_c = C(q,\dot{q})\dot{q}$

### 柔顺控制应用场景

- **装配任务**：
  - 轴孔装配：柔顺搜索+插入
  - 柔性操作：布料、线缆操作
  - 自适应抓取：不同形状物体
- **人机协作**：
  - 安全交互：ISO/TS 15066力限制
  - 协作搬运：力耦合控制
  - 示教编程：人工引导
- **地面适应**：
  - 不平整地面行走：每条腿独立柔顺
  - 软地面（沙地、雪地）：力控制适应
  - 台阶/斜坡：地形自适应
- **碰撞检测与安全**：
  - 力矩异常检测碰撞
  - 碰撞后柔顺退让
  - 紧急停止策略
  - 碰撞力<150N（ISO安全标准）
- **精细操作**：
  - 抛接物体：柔顺接球、力控制抓取
  - 拧瓶盖：旋转力控制
  - 穿针引线：精细力控制

### 触觉感知系统

- **触觉传感器类型**：
  - 电容式：灵敏度高，分辨率好
  - 压阻式：简单，成本低
  - 光学式：基于图像的触觉传感器（GelSight）
  - 压电式：动态响应好
- **触觉信息**：
  - 压力分布：法向力空间分布
  - 切向力：滑动检测
  - 接触位置：精确接触点
  - 物体形状：触觉图像
- **大面积触觉皮肤**：
  - 分布式传感器阵列
  - 覆盖手臂、躯干、腿部
  - 碰撞检测、安全防护
- **力估计方法**：
  - 基于电流的无力传感器力估计
  - 扩展卡尔曼滤波（EKF）
  - 机器学习力估计
- **滑动检测**：
  - 振动信号分析
  - 光学流检测
  - 力变化率检测
  - 调整抓取力防止滑落
