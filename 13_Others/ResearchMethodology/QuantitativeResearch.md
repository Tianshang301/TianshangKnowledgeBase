# 量化研究方法

量化研究是以数字数据为基础，运用统计方法分析变量之间关系的研究方法。它强调客观性、可重复性和推广性，广泛应用于自然科学、社会科学、医学、经济学等领域。

## 研究设计

### 实验设计

实验设计是因果关系研究的金标准：

- **基本要素**：
  - 自变量（Independent Variable）：研究者操纵的变量
  - 因变量（Dependent Variable）：被测量的结果变量
  - 控制变量：保持恒定的变量
  - 随机分配：参与者随机分组
- **类型**：
  - 真实验设计：有随机分配和控制组
  - 前实验设计：无随机分配或控制组
  - 准实验设计：有控制组但无随机分配
- **设计类型**：
  - 组间设计：不同组接受不同处理
  - 组内设计：所有组接受所有处理
  - 混合设计：结合组间和组内
- **优势**：
  - 能确定因果关系
  - 控制混淆变量
  - 内部效度高
- **局限**：
  - 人工环境，外部效度低
  - 伦理限制
  - 实施成本高

### 准实验设计

准实验设计适用于无法随机分配的情况：

- **类型**：
  - 非等组前后测设计
  - 时间序列设计
  - 回归断点设计
  - 匹配设计
- **适用场景**：
  - 教育研究：班级为单位
  - 临床研究：患者分组
  - 组织研究：部门比较
  - 社会研究：社区干预
- **控制方法**：
  - 匹配：在关键变量上匹配
  - 统计控制：使用协变量分析
  - 倾向得分匹配：概率匹配
  - 工具变量：解决内生性问题
- **优势**：
  - 现实情境
  - 可行性强
  - 伦理可行
- **局限**：
  - 因果推断较弱
  - 选择偏差
  - 混淆变量

### 调查研究

调查研究收集大量标准化数据：

- **类型**：
  - 横截面调查：同一时间点
  - 纵向调查：跟踪同一群体
  - 趋势调查：不同时间的不同群体
  - 队列调查：特定出生群体
- **实施方式**：
  - 问卷调查：自填问卷
  - 访谈调查：结构化访谈
  - 电话调查：电话访问
  - 网络调查：在线问卷
- **设计要素**：
  - 抽样框架
  - 问卷设计
  - 实施程序
  - 数据处理
- **优势**：
  - 样本量大
  - 成本较低
  - 标准化程度高
  - 可推广性强
- **局限**：
  - 自我报告偏差
  - 回应率问题
  - 表面效度

## 抽样方法

### 概率抽样

概率抽样确保每个元素有已知概率被选中：

- **简单随机抽样**：
  - 定义：每个元素被选中的概率相等
  - 方法：随机数表、计算机随机
  - 适用：总体同质性高
  - 优点：简单、无偏
- **系统抽样**：
  - 定义：按固定间隔抽样
  - 方法：确定间隔，随机起点
  - 适用：总体有顺序
  - 优点：操作简便
- **分层抽样**：
  - 定义：按层随机抽样
  - 方法：分层，各层随机抽样
  - 适用：总体异质性高
  - 优点：提高精度，确保代表性
- **整群抽样**：
  - 定义：随机抽取群组
  - 方法：随机抽群，群内全查或抽样
  - 适用：地理分散
  - 优点：降低成本，便于操作
- **多阶段抽样**：
  - 定义：分多个阶段抽样
  - 方法：逐层抽样
  - 适用：大规模调查
  - 优点：平衡成本和精度

### 非概率抽样

非概率抽样不保证每个元素有已知概率：

- **便利抽样**：
  - 定义：选择容易获得的样本
  - 方法：自愿者、路过者
  - 适用：探索性研究
  - 缺点：选择偏差大
- **配额抽样**：
  - 定义：按配额选择样本
  - 方法：确定配额，非随机选择
  - 适用：市场调查
  - 缺点：主观选择
- **目的抽样**：
  - 定义：根据研究目的选择
  - 方法：专家判断
  - 适用：质性研究
  - 缺点：主观性强
- **雪球抽样**：
  - 定义：通过已有样本推荐
  - 方法：滚雪球
  - 适用：隐蔽群体
  - 缺点：网络偏差
- **适用场景**：
  - 探索性研究
  - 资源有限
  - 特殊群体
  - 便利性考虑

### 样本量确定

样本量影响研究的统计功效：

- **影响因素**：
  - 效应量：预期效应大小
  - 显著性水平：通常0.05
  - 统计功效：通常0.80
  - 总体变异：数据的变异程度
- **计算方法**：
  - 公式法：根据统计检验公式
  - 软件法：使用G*Power等软件
  - 经验法则：根据经验估计
- **不同研究的样本量**：
  - 描述性研究：大样本
  - 相关研究：中等样本
  - 实验研究：较小样本
  - 结构方程模型：较大样本
- **实际考虑**：
  - 资源限制
  - 时间限制
  - 伦理考虑
  - 缺失数据

## 统计分析

### t检验

t检验比较两组均值差异：

- **类型**：
  - 单样本t检验：样本均值与总体均值比较
  - 独立样本t检验：两独立组均值比较
  - 配对样本t检验：前后测均值比较
- **前提假设**：
  - 正态性：数据正态分布
  - 方差齐性：两组方差相等
  - 独立性：观测值独立
- **检验步骤**：
  1. 建立假设：H0（无差异），H1（有差异）
  2. 计算t值
  3. 确定自由度
  4. 查找临界值或计算p值
  5. 做出决策
- **效应量**：
  - Cohen's d：均值差除以合并标准差
  - 小效应：d=0.2
  - 中效应：d=0.5
  - 大效应：d=0.8
- **报告格式**：
  - t(df)=t值, p=p值, d=效应量

### ANOVA（方差分析）

ANOVA比较多组均值差异：

- **类型**：
  - 单因素ANOVA：一个自变量，多组
  - 双因素ANOVA：两个自变量
  - 重复测量ANOVA：同一被试多次测量
  - 协方差分析（ANCOVA）：控制协变量
- **前提假设**：
  - 正态性：各组数据正态分布
  - 方差齐性：各组方差相等
  - 独立性：观测值独立
- **检验步骤**：
  1. 建立假设：H0（各组均值相等）
  2. 计算F值：组间方差/组内方差
  3. 确定自由度
  4. 查找临界值或计算p值
  5. 事后检验：如果显著，进行多重比较
- **事后检验**：
  - Tukey HSD：比较所有组对
  - Bonferroni：调整显著性水平
  - Scheffé：最保守
  - Dunnett：与控制组比较
- **效应量**：
  - η²（eta平方）：解释的方差比例
  - ω²（omega平方）：总体效应量估计
  - 小效应：η²=0.01
  - 中效应：η²=0.06
  - 大效应：η²=0.14

### 回归分析

回归分析研究变量之间的关系：

- **类型**：
  - 简单线性回归：一个自变量
  - 多元线性回归：多个自变量
  - 逻辑回归：因变量为分类变量
  - 岭回归、Lasso回归：处理多重共线性
- **前提假设**：
  - 线性：自变量与因变量线性关系
  - 独立性：残差独立
  - 正态性：残差正态分布
  - 方差齐性：残差方差恒定
  - 无多重共线性：自变量之间不高度相关
- **分析步骤**：
  1. 建立模型
  2. 估计参数
  3. 模型检验
  4. 变量选择
  5. 模型诊断
- **模型评价**：
  - R²：解释的方差比例
  - 调整R²：考虑变量数量
  - F检验：整体模型显著性
  - t检验：各系数显著性
- **变量选择**：
  - 逐步法：向前、向后、双向
  - 最优子集法
  - 信息准则：AIC、BIC

### 其他方法

- **卡方检验**：
  - 适用：分类变量
  - 类型：拟合优度、独立性、同质性
  - 效应量：Cohen's w、Phi系数
- **相关分析**：
  - Pearson相关：连续变量
  - Spearman相关：等级变量
  - 点二列相关：二分变量
- **非参数检验**：
  - Mann-Whitney U：替代独立t检验
  - Wilcoxon符号秩：替代配对t检验
  - Kruskal-Wallis：替代单因素ANOVA
  - Friedman：替代重复测量ANOVA

## 效应量与统计功效

### 效应量

效应量衡量效应的大小：

- **类型**：
  - 组间效应量：d、g
  - 相关效应量：r、R²
  - 方差分析效应量：η²、ω²
  - 回归效应量：f²
- **解释标准**（Cohen）：
  - 小效应：d=0.2, r=0.1, η²=0.01
  - 中效应：d=0.5, r=0.3, η²=0.06
  - 大效应：d=0.8, r=0.5, η²=0.14
- **报告要求**：
  - 效应量点估计
  - 置信区间
  - 解释标准
- **重要性**：
  - 实际意义
  - 元分析基础
  - 样本量规划
  - 研究比较

### 统计功效

统计功效是正确拒绝错误假设的概率：

- **定义**：1-β（β为第二类错误概率）
- **影响因素**：
  - 效应量：效应越大，功效越高
  - 样本量：样本越大，功效越高
  - 显著性水平：α越小，功效越低
  - 检验类型：单尾vs双尾
- **计算方法**：
  - 公式法：根据统计检验公式
  - 软件法：使用G*Power等软件
  - 图表法：功效曲线图
- **标准**：
  - 通常要求0.80
  - 高要求0.90
  - 最低0.70
- **应用**：
  - 样本量规划
  - 研究设计
  - 结果解释
  - 元分析

### 样本量规划

样本量规划确保研究有足够的统计功效：

- **步骤**：
  1. 确定检验类型
  2. 设定显著性水平（通常0.05）
  3. 设定统计功效（通常0.80）
  4. 估计效应量
  5. 计算所需样本量
- **方法**：
  - 公式法：根据统计检验公式
  - 软件法：G*Power、R、Stata
  - 经验法则：根据文献
- **实际考虑**：
  - 预期流失率
  - 资源限制
  - 时间限制
  - 伦理考虑
- **报告**：
  - 参数设定
  - 计算方法
  - 最终样本量
  - 预期功效

## 量化研究的现代发展

### 大数据分析

大数据对量化研究的影响：

- **特点**：
  - 数据量大
  - 生成速度快
  - 数据类型多样
  - 价值密度低
- **方法**：
  - 机器学习
  - 数据挖掘
  - 预测建模
  - 模式识别
- **应用**：
  - 商业分析
  - 社交媒体分析
  - 医疗健康
  - 城市规划
- **挑战**：
  - 数据质量
  - 隐私保护
  - 算法偏见
  - 因果推断

### 开放科学

开放科学运动的影响：

- **原则**：
  - 开放获取
  - 开放数据
  - 开放方法
  - 开放同行评审
- **实践**：
  - 预注册研究
  - 共享数据和代码
  - 开放获取出版
  - 重复性研究
- **好处**：
  - 提高透明度
  - 促进合作
  - 加速发现
  - 提高可信度
- **挑战**：
  - 激励机制
  - 隐私问题
  - 资源需求
  - 文化变革

### 人工智能辅助

人工智能在量化研究中的应用：

- **数据收集**：
  - 网络爬虫
  - 自然语言处理
  - 图像识别
  - 传感器数据
- **数据分析**：
  - 机器学习算法
  - 自动编码
  - 模式识别
  - 预测建模
- **研究辅助**：
  - 文献综述
  - 假设生成
  - 实验设计
  - 结果解释
- **挑战**：
  - 算法透明度
  - 数据偏见
  - 伦理问题
  - 技能需求

### 混合方法研究

混合方法结合质性和量化：

- **类型**：
  - 解释性序列：量化先行，质性解释
  - 探索性序列：质性先行，量化验证
  - 并行式：同时进行
  - 嵌入式：一种方法嵌入另一种
- **优势**：
  - 互补优势
  - 全面理解
  - 验证发现
  - 不同视角
- **设计要素**：
  - 优先级：哪种方法优先
  - 顺序：先后或同时
  - 整合：如何整合结果
  - 理论框架：指导研究的理论
- **挑战**：
  - 范式冲突
  - 资源需求
  - 整合困难
  - 评价标准
